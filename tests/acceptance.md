# Manual acceptance checklist

- [ ] At 320, 768, 1024, and 1440 CSS px, the page does not create viewport-level horizontal scrolling.
- [ ] Tab and Shift+Tab reach every interactive element in a logical order; focus is visible.
- [ ] Escape closes dialogs and returns focus to the invoking control.
- [ ] Search, category chips, and sort work together without a page reload.
- [ ] Add/remove/change cart quantity updates the announced count and persists after refresh.
- [ ] An API failure shows a readable status message and leaves sample products available.
- [ ] Labels, validation messages, live status, and table headings are exposed to assistive technology.
- [ ] Test HTML with the W3C Nu Validator and record the result in the evidence log.
